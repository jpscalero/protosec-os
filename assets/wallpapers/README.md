# Assets — Fondos de Pantalla de ProtoSec OS

Esta carpeta contiene los fondos de pantalla oficiales de la distribución:

- **`protosec-default.png`**: El fondo de pantalla por defecto generado dinámicamente con detalles verde neón y el eslogan centrado.

Puedes regenerar el wallpaper en cualquier momento utilizando el script ubicado en la raíz del repositorio:
```bash
python3 scripts/wallpaper-generator.py
```
